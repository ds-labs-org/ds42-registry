# Examples

Filled-in JSON-LD entries, one per role, showing the shape
[`schema/ontology.ttl`](../../schema/ontology.ttl) (the vocabulary) and
[`schema/shapes.ttl`](../../schema/shapes.ttl) (what CI enforces)
describe. Documentation only — this directory is excluded from CI
validation and from auto-merge eligibility (see
[`.github/workflows/validate.yml`](../../.github/workflows/validate.yml)),
so nothing here needs to stay a real, reachable entry.
